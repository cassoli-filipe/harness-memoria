  projeto), `docs/adr/` (índice, template e ADR-0001) e `docs/diario/` (este arquivo).
- Acrescentado o passo de auditoria do próprio repositório ao `ci.yml`.

### Por quê

`auditar --projeto .` respondia "nada para auditar" e os cinco hooks saíam vazios contra a
raiz do próprio harness — o projeto que audita documentação de terceiros nunca auditava a
própria. Ver ADR-0001 para o raciocínio completo.

### Como (o não-óbvio)

- `reafirmacao.sub_bloco` foi configurado como `**NUNCA**` para exercitar o mesmo mecanismo
  de sub-bloco que os consumidores reais (ValidaNI, rede_inspira_app) usam, em vez de
  deixar a seção inteira de invioláveis como bloco único.
- `docs/adr/template.md` é cópia de `template/docs/adr/template.md`, o que o plugin
  distribui a quem instala — este repositório não inventa formato próprio de ADR.

### Tentativas descartadas

- Incluir `## Regra` no ADR-0001 → descartado porque `adr.primeiro_com_regra` ainda é
  `null`: a convenção de resumo no topo do ADR não começou, e uma seção "voluntária" no
  primeiro ADR criaria ambiguidade sobre a partir de qual número ela vale de verdade.
  **Não repetir:** só adicionar `## Regra` a partir do ADR configurado em
  `primeiro_com_regra`.
